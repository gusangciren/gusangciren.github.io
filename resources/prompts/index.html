从热门观点中寻找反常识选题

检验常见观点，寻找它不成立的条件和被忽略的因素。

你是一位擅长独立思考的选题编辑。

围绕【主题】，找出这个领域中广泛流行的观点、普遍接受的经验和常见建议。

然后逐一追问：

1. 这个观点一定正确吗？
2. 它在什么情况下不成立？
3. 它忽略了什么重要因素？
4. 有没有与之相反的真实案例？
5. 有没有一种更准确、更深刻的解释？

请从中提炼 10 个具有讨论价值的文章选题。

注意：不要为了反常识而反常识。每个选题都必须有合理的推理基础。

从商业目标反推内容选题

让内容和产品形成长期关系，而不是每篇文章都像广告。

我的长期目标是通过内容建立信任，并销售自己的产品。

目前我销售的产品是：【产品介绍】。
目标读者是：【目标读者】。

请你从商业目标反推内容选题。

分为四种类型：

1. 流量型：帮助陌生读者发现我。
2. 信任型：展示我的思考、经验和专业能力。
3. 需求型：让读者意识到自己存在某个问题。
4. 转化型：帮助读者理解产品能够解决什么问题。

每种类型分别提供 5 个选题。

注意：
- 不要让所有文章都像广告。
- 不要每篇文章都强行推销产品。
- 让选题之间形成连续的内容关系。
- 让读者从认识一个问题，逐渐走向理解解决方案。

【产品介绍】：

09 / PROMPT
选题发现

从一个主题中寻找值得写的观点

从一个主题里，从读者问题、常见观点的反直觉处和深层问题三个角度，寻找值得写的观点。

你是一名擅长发现内容选题和独立观点的编辑。

我想深入写的主题是：【填写主题】。

请不要直接给我文章标题，也不要直接写文章。请围绕这个主题，从三个角度帮我寻找值得写的观点：

一、从读者的问题出发
站在普通读者的角度，找出他们在这个领域真正遇到的问题：
1. 他们经常遇到什么麻烦？
2. 他们想实现什么目标，却不知道怎么做？
3. 他们有哪些错误认知？
4. 他们反复搜索什么问题？
5. 有哪些问题他们意识到了，却不知道该如何表达？
6. 有哪些需求目前没有得到很好的满足？

二、从常见观点的反直觉处切入
列出这个主题中最常见的 10 个观点，然后逐一追问：
- 这些观点成立的前提是什么？
- 在什么情况下它们可能不成立？
- 它们忽略了哪些因素？
- 有没有被忽视的相反证据？
- 有没有更准确、更有解释力的表达方式？

三、把主题拆成值得研究的问题
提出 20 个值得深入研究的问题，它们应当：
1. 能够引发思考，而不是简单罗列常识。
2. 能够引出不同于常见观点的解释。
3. 可以通过真实案例、个人经历或原始资料进行研究。
4. 尽量寻找人们习以为常、但很少认真思考的地方。
5. 不要为了制造新颖感而故意提出荒谬的问题。

最后，综合以上三个角度，请提出 10 个值得进一步写作的切入点，并说明：
- 它针对的是读者问题、常见观点的盲区，还是尚未被充分讨论的角度？
- 为什么它值得写？
- 需要什么证据或案例才能支撑？

注意：反常识不等于故意唱反调，请优先寻找有证据支持、能够解释现实的观点；对于需要事实验证的判断，请明确标注待核实之处。选题尽量使用读者自己的语言，而不是行业术语。

观点挖掘

把普通话题挖掘出不同角度

从历史、商业、心理、经济、技术等视角扩展思考。

我准备写一篇关于【主题】的文章。

请不要急着给我文章大纲。

你需要像一位优秀的编辑一样，帮助我寻找这个主题中尚未被充分讨论的角度。

请分别从以下方向展开：

1. 历史角度：这个问题过去是怎样的？
2. 商业角度：它背后有什么商业规律？
3. 心理角度：人们为什么会这样做？
4. 经济角度：成本、收益和激励机制是什么？
5. 技术角度：技术变化带来了什么新机会？
6. 反面角度：如果从相反的立场看，会得到什么结论？
7. 个体角度：普通人可以从中获得什么启发？

每个角度至少提出 2 个值得写的问题。

不要给我重复的观点，要尽可能扩大思考范围。

观点挖掘

反向思考研究员

从相反方向检验主流观点，寻找另一种解释。

我正在研究的问题是：【问题】。

请尝试从相反的方向思考。

1. 当前主流观点是什么？
2. 如果这个观点是错的，可能是什么原因？
3. 哪些条件下它不成立？
4. 有没有被忽略的反面案例？
5. 有没有另一种解释能够更好地解释现实？
6. 如果完全反过来思考，会得出什么结论？

请寻找证据，而不是为了反驳而反驳。

最后给出3个值得进一步研究的反向观点。

观点挖掘

使用类比产生新观点

找到解释复杂问题的新方式。

我正在研究的问题是：【填写问题】。
请为这个问题寻找 10 个来自不同领域的类比。
可以从生物学、工程学、历史、心理学、商业、体育和日常生活中寻找。
对每个类比，请说明：
1. 两个事物的相似之处。
2. 这种相似性能够帮助我们理解什么。
3. 类比在哪些地方不成立。
4. 它可能引出什么值得研究的新观点。
不要只追求有趣的比喻，要寻找能够帮助我们推理的类比。
最后选出三个最适合发展成文章的类比。

研究与素材

原始资料研究员

研究人物、公司或商业事件时，从商业问题切入，优先寻找一手材料、核实出处，并产出可写的文章选题。

我想深入研究：【人物、公司或商业事件】。

请不要只给我二手文章、常见总结或人物介绍，也不要直接罗列成功经验。

请先寻找值得研究的商业问题，例如：
- 最初如何发现机会？
- 在什么时间做出了关键决策？
- 如何获得第一批客户？
- 如何把内容转化为收入？
- 采用了什么低成本实验？
- 哪些结果可能来自运气、时机或已有资源？
- 哪些方法适合普通创作者借鉴？

优先寻找一手材料：
1. 当事人自己写的文章。
2. 完整采访、播客和公开视频。
3. 原始演讲。
4. 官方产品页面。
5. 公开的商业数据。
6. 当事人亲自分享的经营经验。

请建立时间线。

对每个重要结论，提供：
- 具体事实。
- 原始出处。
- 出处中的相关内容。
- 这件事说明了什么。
- 哪些地方还无法确定。

最后提出 10 个有研究价值的文章选题，并说明每个选题需要什么证据才能成立。

不要编造资料、收入、时间线或人物言论，不要将二手观点伪装成当事人的原话。

选题评估

选题压力测试

从读者需求、独特性、观点空间、素材、传播和产品关联评估选题。

你是一位严格的内容总编辑。

我会提供一个文章选题：【选题】。

请不要鼓励我，也不要急着帮我写文章。

请从以下维度评估它：

1. 读者需求：有没有人真正关心这个问题？
2. 独特性：这个选题是否已经被大量讨论？
3. 观点空间：能否形成有价值的独立观点？
4. 素材空间：有没有足够的案例、数据和原始资料？
5. 实用价值：读者读完能获得什么？
6. 传播潜力：标题是否能激发好奇心？
7. 产品关联：它是否能够自然连接到某个产品或服务？

每项给出 1—10 分。

最后告诉我：
- 这个选题最大的优点是什么？
- 最大的问题是什么？
- 应该保留、修改还是放弃？
- 如果修改，最值得尝试的三个新切口是什么？

请给出真实判断，不要为了让选题看起来不错而打高分。

【选题】：

商业与变现

从一个问题中发现商业机会

将内容创作与创业研究连接起来。

我正在研究的问题是：【填写问题】。
请把它当作一个潜在的商业机会来研究。
帮助我回答：
1. 谁会遇到这个问题？
2. 他们多久遇到一次？
3. 问题会带来什么具体损失？
4. 他们现在如何解决？
5. 现有方案有什么缺陷？
6. 他们是否已经为替代方案付过钱？
7. 我可以用什么最小成本的方式验证需求？
请区分已经掌握的事实与待验证的假设。
最后提出三个低成本验证实验，不要一开始就建议我开发完整产品。

商业与变现

处理客户的购买异议

诚实回应客户在购买前的真实顾虑。

我销售的产品是：【产品】。
目标客户：【客户】。
产品价格：【价格】。
请模拟客户购买前可能提出的 10 个真实问题或异议。
例如：
- 为什么我需要购买？
- 网上有没有免费的替代品？
- 这个产品适合我吗？
- 我购买后能得到什么？
- 为什么价格是这个水平？
对每个异议，请提供：
1. 客户真正担心的是什么。
2. 我应该提供什么证据。
3. 如何诚实地回答。
4. 哪些情况下应该承认产品不适合客户。
不要把所有异议都当作需要反驳的问题。

文章编辑

保留作者风格的编辑器

提高准确性与可读性，而不代替你写作。

请作为我的中文文章编辑。
你的任务是提高文章的准确性、清晰度和可读性，而不是代替我写作。
【粘贴文章】
请遵守以下原则：
1. 尽量保留原文的观点、逻辑和语言习惯。
2. 修正错别字、标点错误和明显的语音转文字错误。
3. 调整确实影响阅读的句子。
4. 保留有意义的比喻、类比和个人表达。
5. 不擅自增加新的观点、案例或结论。
6. 不把文章改成夸张的营销文案。
7. 不要机械地增加小标题。
8. 不要把每句话都单独分成一段。
先指出需要修改的问题，再提供最小幅度的修改稿。
对涉及观点变化的修改，必须单独说明，不要直接替我决定。
