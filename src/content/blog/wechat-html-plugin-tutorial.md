我在 Obsidian中给自己做了一个公众号排版插件。**写完就可以直接复制发布**。

以前，我用一个在浏览器中编辑使用的排版网站，我使用了一两年。但有几个非常难受的地方，文件新建多了，就开始收费了。其次，更令人难受的是——我只能在他们给定的主题范围内进行选择。

我想对 CSS 进行一点修改，让它更好看，让排版功能更加个性一点、拥有品牌性一点，但我并不会写作代码。

但就在这个周末，我用一个小时定制了属于自己的公众号版本插件。效果见头图。

步骤大概这样的，共四步：

* 1、让 agent 安装一个 Obsidian 公众号排版插件。我安装了WeChat Rich Text Preview插件。
* 2、从别的公众号博主那里找到自己满意的排版，然后把文章链接丢给 AI。如果你喜欢这篇文章的排版，那就保存这篇文章的链接🔗。
* 3、让它根据文章链接的排版风格来修改你的WeChat Rich Text Preview插件。
* 4、有任何的不满意和需要个性化修改的地方，随时和 AI 聊天。

向 AI 提问的好处在于——你不需要思考面子。如果你像领导同事问基础问题三四遍，同事心烦是一回事，重要的是你不再“敢问”了。**面对 AI，你可以是一个「蠢货」。**
