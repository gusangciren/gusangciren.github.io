### 🧰 创作工具箱

打开 [工具箱](https://gusangciren.github.io/tools)，全部在浏览器里完成，**你的文字不会上传到任何服务器**：

- **公众号封面制作**：输入标题，选配色与布局，复制图片直接当公众号封面；
- **句子卡片**：输入一句话，生成仿推文风格的卡片，复制或下载 PNG，发朋友圈、公众号都合适；
- **书写伙伴**：Markdown 写作 + 白噪音（雨声、森林）+ 专注计时，写完一键复制成公众号排版，粘贴即用。
